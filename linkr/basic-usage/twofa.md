# Two-Factor Authentication (2FA)

Radxa Linkr supports TOTP-based two-factor authentication. After enabling it, in addition to the username and password, you also need to enter a 6-digit code generated by an authenticator when logging in, further improving account security.

## Prerequisites

Please install a TOTP-compatible authenticator on your phone or other trusted device in advance, for example:

- [Google Authenticator](https://support.google.com/accounts/answer/1066447?hl=en)
- [Microsoft Authenticator](https://support.microsoft.com/en-us/authenticator/about-microsoft-authenticator)
- [Bitwarden Authenticator](https://bitwarden.com/help/bitwarden-authenticator/)
- [1Password](https://support.1password.com/one-time-passwords/)

You can also use other TOTP authenticators that support scanning QR codes or manually entering keys.

:::warning Important
The current version does not generate recovery codes. After enabling 2FA, please keep the authenticator and 2FA key safe. Do not share the QR code, key, or verification code with others.
:::

## Enable Two-Factor Authentication

Go to the Linkr management page: System Settings -> Security -> Enable the Two-factor Authentication (2FA) option.

<div style={{textAlign: 'center'}}>
   <img src="/en/img/linkr/linkr-2fa-bind.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

① Click the System Settings option

② Enable the 2FA feature

③ Use the authenticator to scan the QR code on the page, then enter the 6-digit code generated by the authenticator.

④ Click Confirm to complete the operation

If you cannot scan the QR code, you can copy the key displayed on the page and add it manually in the authenticator.

<div style={{textAlign: 'center'}}>
   <img src="/en/img/linkr/linkr-2fa-succ.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

## Log in with Two-Factor Authentication

After enabling 2FA, you also need to provide the 6-digit code generated by the authenticator when logging in.

<div style={{textAlign: 'center'}}>
   <img src="/en/img/linkr/linkr-2fa-login.webp" style={{width: '100%', maxWidth: '1200px'}} />
</div>

## Disable Two-Factor Authentication

Go to the Linkr management page: System Settings -> Security -> Click the option to disable two-factor authentication.
